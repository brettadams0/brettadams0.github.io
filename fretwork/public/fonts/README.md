# Bundled fonts

Both faces are self-hosted rather than fetched from a CDN so that the panel
type still renders when the device is offline, which is the normal case for
this app.

| File | Family | Licence |
| --- | --- | --- |
| `barlow-condensed-400.woff2`, `barlow-condensed-600.woff2` | Barlow Condensed, by Jeremy Tribby | SIL Open Font License 1.1 |
| `ibm-plex-mono-400.woff2`, `ibm-plex-mono-600.woff2` | IBM Plex Mono, by IBM | SIL Open Font License 1.1 |

The SIL OFL 1.1 permits redistribution of the font files, bundled with
software, provided the licence travels with them: <https://openfontlicense.org>.
Neither family is renamed here, and neither is sold on its own.

These are the Google Fonts `latin` subsets, which is why they are ~15–22 KB
each rather than the full multi-script originals.
