      How it works
      
    
        
      
      • A broken MCP server can look connected while the AI assistant gets a worse tool or none at all. These checks catch that.
        • 
      
      • The checks are the npm package's own code, mcp-surface 0.3.0, bundled for the browser with esbuild.
        • 
      
      • This page only reads what is in the editor, hands it to those checks the way the command-line tool does, and draws the result.
        • 
      
      • Nothing you type leaves this tab.
