Under the hood C++ · WebAssembly · Web Worker · seeded RNG

The actual C++ engine runs in a Web Worker so the interface stays responsive. The native CLI evaluates fitness with a thread pool; this browser build uses one worker.

Fitness = distance remaining × (genome length + 1) + moves used. Distance is measured by breadth-first search (BFS). The BFS distance field guides fitness and some mutations: this is a hybrid genetic search. Guided mutations rewrite route segments toward the goal and expand after a plateau. The dashed overlay is the BFS shortest path, not an evolved route. A lower score wins.

The population has 100 genomes, each at least 100 moves or 1.5× the shortest path. Replay links save maze settings and seed, starting again at generation zero. The timeline records real improvements from this run; inspecting one pauses evolution and never changes the population. Moving dots replay routes, not extra simulation steps. 40 × 40 uses loops to keep searches practical; a solution within the budget is not guaranteed. Keep evolving extends a run in 1,500-generation blocks, up to 15,000.
