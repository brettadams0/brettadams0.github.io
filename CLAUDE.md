# Notes for working on this site

- Brett's favourite thing on the site is the neuronet-arena live demo (`/neuronet-arena/`). More
  interactive, live, in-browser showcases of real projects like it are very welcome. Build them from the
  project's actual code, not a mock-up.
- Nothing live runs on the homepage. It shows still previews that link to the demos, and a demo starts
  only on its own page, after the visitor clicks through. `handoff/` holds briefs for queued work, such
  as the MazeFinder demo.
- No blog posts. Brett removed them as AI-sounding. Keep site copy short and factual: one line per
  project, facts as chips. The `/mcp/` case study is the one long-form page, kept because Brett merged it.
- Visual style: dark only, the tokens in `assets/css/site.css` (shared with the demos), IBM Plex Sans/Mono.
- `neuronet-arena/` is synced from another repo; see README before editing it.
