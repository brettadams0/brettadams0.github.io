mcp-surface

A command-line tool and GitHub Action for testing Model Context Protocol servers. It connects the way a client does, lists the tools a server actually exposes, and runs 19 checks on their schemas. It can also snapshot that tool list and fail CI when it changes, which is how it caught a dependency upgrade that changed all 23 of my Google Workspace tools while every unit test passed.

TypeScript · Node.js · Published on npm

MCP servers for Google Workspace and Reddit

Two servers that let an AI assistant act on real accounts: 23 tools that send email and manage Calendar, Drive, Sheets and YouTube, and 12 that read, post, vote and message on Reddit. Both treat every tool argument as untrusted, because a model that has just read an email can be steered by it. Tests run offline on Node 22 and 24, and mcp-surface checks each server's tool list against a committed snapshot as the last step of CI.

JavaScript · Node.js · OAuth 2.0

PromptPal

A browser tool for writing prompt templates. Templates have fields and optional sections in a small language with its own parser, which reports errors by line and column. PromptPal fills the template in, checks the result for empty required fields and leftover text like “[insert topic]”, and exports it as text or a ready-to-run Claude API call. There is no backend; share links carry the prompt in the URL fragment. Unit, end-to-end and accessibility tests run in CI.

TypeScript · Next.js · React · Tailwind CSS

neuronet-arena

An evolution simulator. Forty agents, each steered by a small neural network, compete for food, and the ones that eat the most breed the next generation. The network, the genetic algorithm and the random number generator are written from scratch in Python, then ported to JavaScript for a live demo that reproduces the Python engine bit for bit. Against a control run with selection switched off, evolved agents eat 13.4 food each to the control's 1.0.
