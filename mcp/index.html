Case study · Model Context Protocol

Five MCP servers, and the tool that checks them

I build Model Context Protocol servers that let an AI assistant act on real accounts — send email, write a spreadsheet, post to Reddit, read a fantasy league — and a published CLI, mcp-surface, that connects to a server the way a client does and reports what it actually exposes. Every server's CI runs it against a committed snapshot, so the tools a model sees can only change through a reviewed diff.

One gate for every server

A broken MCP server rarely looks broken. It starts, it completes the handshake, the client prints Connected — and the model quietly gets a worse tool, or none. Unit tests don't catch it either, because they assert on handlers, not on the surface a client is actually shown. So every server's CI ends with the same step:

  1. 1Start the real server over stdio, exactly as a client launches it — no credentials needed to list tools.
  2. 2Read initialize and tools/list raw, so one malformed tool is reported by name instead of failing the whole list.
  3. 3Check every schema, name and annotation, and hold the definitions to a size budget — they are resent on every request.
  4. 4Diff against the committed mcp-surface.json. Any change fails the build until the snapshot is updated in the same pull request.

It earned its place on the first day. Upgrading the schema library from Zod 3 to Zod 4 looked like a routine dependency bump; every test still passed. mcp-surface flagged all 23 Google tools as changed: the new version stopped emitting additionalProperties: false and added a 120-byte email regex to every address field, pushing the server over its definition budget. The upgrade was backed out before it shipped.

The servers

Five upstream APIs, chosen partly because each one authenticates differently.

google-workspace-mcp

read + write

23 tools · Gmail, Calendar, Drive, Sheets, YouTube

Auth: a self-owned Google OAuth client, deliberately requesting only write scopes to stay out of Google's paid restricted-scope audit. PKCE, state, loopback-only callback.

Code

reddit-mcp

read + write

12 tools · posts, comments, votes, messages

Auth: OAuth2 with a refresh token Reddit never rotates. Writes post publicly under a real account, so ids are type-checked and rejections are surfaced, never assumed away.

Code

supercell-mcp

read-only

15 tools · Clash of Clans, Clash Royale, Brawl Stars

Auth: static API keys, each bound to a single public IP. A 403 says which IP Supercell saw — the exact value the developer portal asks for.

Code

yahoo-fantasy-mcp

read-only

10 tools · leagues, rosters, matchups

Auth: OAuth2 with a refresh token Yahoo rotates on every use — which turns parallel tool calls into a race, and is why refresh is single-flight.

Code

chesscom-mcp

read-only

9 tools · profiles, ratings, games, clubs

Auth: none — a public API. The interesting problem is size: a month of games for an active player is megabytes, so results are summarised by default.

mcp-surface

npm · Action

CLI · library · GitHub Action · TypeScript

Probes a server over stdio, Streamable HTTP or SSE; 19 checks; canonicalised snapshots; a --call mode that only invokes tools annotated read-only with no required arguments. Published with npm provenance.

What a hardening pass found

The premise of the pass: every tool argument is model output, and a model that has just read a web page or an email can be steered by what it read. A server that sends mail and writes spreadsheets has to treat its inputs the way a web server treats a form post. Each item below shipped with a test that builds the hostile input.

Security · google-workspace-mcp

Header injection through a subject line

Subjects, addresses and filenames were written straight into the MIME message, so Hi\r\nBcc: someone@example.com added a recipient. Line breaks are now refused, and non-ASCII text is encoded per RFC 2047 and 2231.

Security · google-workspace-mcp

Formula injection into a spreadsheet

Writes used USER_ENTERED, which evaluates =IMPORTDATA("https://…"&A1) as a live formula able to send the sheet anywhere. Values are now written raw; formula parsing is an explicit opt-in.

Security · reddit-mcp, yahoo-fantasy-mcp

Path traversal, with the token attached

URL resolution collapses .., so a subreddit named ../api/v1/me reached a different endpoint carrying the account's bearer token. Segments are validated, and Yahoo's requests are checked after resolution, before the token is read.

Correctness · reddit-mcp

A 200 that means no

Reddit reports a rejected post — misspelt subreddit, rate limit — as HTTP 200 with the reasons buried in the body, so the model could announce a post that never existed. Rejections are now errors that name Reddit's reasons.

Correctness · yahoo-fantasy-mcp

A token-rotation race

Parallel calls at expiry each presented the same single-use refresh token; all but one failed, and the token left on disk could be the spent one. Refresh is single-flight, and a test drives four calls through an expiry.

Correctness · google-workspace-mcp

Invitations nobody received

The Calendar API emails no one unless asked, so "invite Alice" produced an event Alice never heard about — while the tool's description said otherwise. Attendees are now notified by default, with an explicit opt-out.

Correctness · supercell-mcp

A credentials file nobody could create

The Clash of Clans client read coc.json while the docs, the example file and the error message all said clashofclans.json. A test now ties each client's file to its tracked example.

Context cost · chesscom-mcp

2.27 MB → 238 KB

One titled player's month was 509 games and 2.27 MB of JSON, far past any client's output cap, so the model saw a fragment. Games are now summarised without move records by default, with a time-class filter and PGN on request.

Footprint · google-workspace-mcp

282 MB → 45 MB

The monolithic googleapis package bundles every Google API there is. Five per-API packages replaced it, and with them a dependency override that existed only to work around the old one.

The shared baseline

Each repository meets the same bar, so none of them is the one that got skipped.

  • Offline tests on Node 20, 22 and 24 — no network, no credentials, request-level assertions through recording stubs.
  • A committed tool surface that CI holds the running server to, with a definition-size budget.
  • MCP annotations on every tool — read-only, destructive, idempotent — so a client can auto-approve reads and prompt for writes.
  • Bounded failure: 30-second timeouts, trimmed error bodies, and rate-limit errors that say when to retry.
  • Compact results, because tool output is model context and indentation is pure token cost.
  • Zero open npm audit advisories at release, ESLint, monthly Dependabot, a changelog and a security policy.

The longer story of why mcp-surface exists is on the blog: Connected Is Not a Health Check.
